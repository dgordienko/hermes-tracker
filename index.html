What it is

Что это

Що це

Hermes Tracker is the company's Android application for field sales agents and couriers. It records vehicle GPS routes in the background and lets agents check in at delivery points. The app is a native replacement for the equivalent features of the legacy Distributor application and stays compatible with the same server API, so both apps can run side by side against the same backend.

Hermes Tracker — корпоративное Android-приложение для торговых агентов и курьеров компании. Оно записывает GPS-маршрут автомобиля в фоновом режиме и позволяет агенту отмечаться (чек-ин) на точках доставки. Приложение — нативная замена соответствующих функций устаревшего приложения Distributor и совместимо с тем же серверным API, поэтому оба приложения могут работать параллельно против одного бэкенда.

Hermes Tracker — корпоративний Android-застосунок для торгових агентів і кур'єрів компанії. Він записує GPS-маршрут автомобіля у фоновому режимі та дозволяє агенту відмічатися (чек-ін) на точках доставки. Застосунок є нативною заміною відповідних функцій застарілого застосунку Distributor і сумісний із тим самим серверним API, тому обидва застосунки можуть працювати паралельно проти одного бекенду.

Route recording

Запись маршрута

Запис маршруту

  • Background recording via a foreground service — continues with the screen off or the app closed from "Recents".
  • Фоновая запись через foreground-сервис — продолжается при выключенном экране и при закрытии приложения с экрана «Недавние».
  • Фонове записування через foreground-сервіс — продовжується при вимкненому екрані та при закритті застосунку з екрана «Останні».
  • Automatic recovery if the recording service is killed by the system or aggressive OEM battery management.
  • Автоматическое восстановление записи, если сервис был неожиданно завершён системой или агрессивным управлением батареей производителя.
  • Автоматичне відновлення запису, якщо сервіс було несподівано завершено системою чи агресивним керуванням батареєю виробника.
  • Optional recording time window (default 06:00–21:00); outside it, recording can't be started and is stopped automatically.
  • Опциональное окно времени для записи (по умолчанию 06:00–21:00); вне окна запись нельзя начать, а идущая — останавливается автоматически.
  • Опційне вікно часу для запису (за замовчуванням 06:00–21:00); поза вікном запис не можна почати, а активний — зупиняється автоматично.
  • Track history with upload status, a route map (OpenStreetMap tiles, no Google Maps SDK or API key), and a full point table.
  • История треков со статусом выгрузки, карта маршрута (тайлы OpenStreetMap, без Google Maps SDK и API-ключа) и таблица всех точек.
  • Історія треків зі статусом вивантаження, карта маршруту (тайли OpenStreetMap, без Google Maps SDK та API-ключа) і таблиця всіх точок.
  • Reliable background upload with automatic retry; uploaded tracks are removed from the device the next day.
  • Надёжная фоновая выгрузка с автоматическими повторами; выгруженные треки удаляются с устройства на следующий день.
  • Надійне фонове вивантаження з автоматичними повторами; вивантажені треки видаляються з пристрою наступного дня.

Delivery points

Точки доставки

Точки доставки

  • Point list and work conditions synced from the server, cached locally and refreshed only when data actually changes.
  • Список точек и условия работы синхронизируются с сервера, кэшируются локально и обновляются только при реальном изменении данных.
  • Список точок та умови роботи синхронізуються з сервера, кешуються локально й оновлюються лише за реальної зміни даних.
  • Search by code, address, name or linked counterparty, with combinable filters — has coordinates, position refined, registered today.
  • Поиск по коду, адресу, названию или связанному контрагенту, с комбинируемыми фильтрами — есть координаты, позиция уточнена, зарегистрирована сегодня.
  • Пошук за кодом, адресою, назвою чи пов'язаним контрагентом, з фільтрами, що комбінуються — є координати, позицію уточнено, зареєстровано сьогодні.
  • Check-in with distance validation against the agent's averaged GPS position (default threshold 150 m), with a warning if too far.
  • Чек-ин с проверкой расстояния до усреднённой GPS-позиции агента (порог по умолчанию 150 м), с предупреждением при превышении.
  • Чек-ін із перевіркою відстані до усередненої GPS-позиції агента (поріг за замовчуванням 150 м), із попередженням у разі перевищення.
  • Coordinate refinement, validated against Ukraine's border, with separate registration and refinement timestamps.
  • Уточнение координат точки с проверкой попадания в границы Украины и отдельными отметками времени регистрации и уточнения.
  • Уточнення координат точки з перевіркою входження в межі України та окремими позначками часу реєстрації й уточнення.
  • Open a point directly in Google Maps, with a fallback to the system geo: handler.
  • Открытие точки в Google Maps с фоллбеком на системный обработчик geo:.
  • Відкриття точки в Google Maps із фолбеком на системний обробник geo:.

Settings & reliability

Настройки и надёжность

Налаштування та надійність

  • Recording notification sound on/off, and a configurable recording time window.
  • Звук уведомления о записи (вкл/выкл) и настраиваемое окно времени для записи.
  • Звук сповіщення про запис (увімк/вимк) та налаштовуване вікно часу для запису.
  • Editable API server address, so the app can point at a test/staging server without rebuilding.
  • Редактируемый адрес API-сервера — можно направить приложение на тестовый сервер без пересборки.
  • Редагована адреса API-сервера — можна спрямувати застосунок на тестовий сервер без перезбирання.
  • Dark and light theme, switched instantly across the whole app.
  • Тёмная и светлая тема, переключается мгновенно во всём приложении.
  • Темна і світла тема, перемикається миттєво в усьому застосунку.
  • Interface localized in English, Russian and Ukrainian.
  • Интерфейс локализован на английском, русском и украинском языках.
  • Інтерфейс локалізовано англійською, російською та українською мовами.
  • Crash and error monitoring via Sentry, to catch and fix issues in the field quickly.
  • Отслеживание крашей и ошибок через Sentry — для быстрого выявления и исправления проблем в поле.
  • Відстеження крашів і помилок через Sentry — для швидкого виявлення й виправлення проблем у полі.
